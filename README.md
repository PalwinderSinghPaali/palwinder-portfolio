## ⚡ Running Locally

### Requirements

* Node.js 18.17+
* npm

### Installation

```bash
git clone https://github.com/PalwinderSinghPaali/palwinder-portfolio.git

cd palwinder-portfolio

npm install

npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
