## Overview

TraceBale by CottonConnect is a comprehensive digital traceability platform designed to help brands and retailers map their supply chains effectively. By tracking cotton and other raw materials from farm group level to the finished product, TraceBale strengthens supply chain resilience and ensures near real-time transparency at each critical stage.

The platform has been enhanced with advanced capabilities, including AI-driven document mapping, geolocational sales tracking, physical stock verification, and custom anomaly reporting.

## Key Features

- **AI Invoice Mapping & Data Extraction**: Leverages AI models to parse invoices, receipts, and shipping manifests, automatically mapping transaction data and reducing manual entry errors.
- **Physical Stock Verification**: Integrates physical verification checkpoints to cross-reference digital logs with actual warehouse inventory levels, resolving discrepancies.
- **Anomaly Detection & Graph Reports**: Uses analytical models to highlight data inconsistencies (e.g. weight mismatch, transaction loops) and renders them in visual dashboards and exportable reports.
- **Geo-Tracking for Sales**: Implemented location-based tracking for sales and shipments, enabling stakeholders to audit raw material movement and detect unauthorized diversion.
- **Pre-Lint Order Functionality**: Manages raw cotton orders and lint requirements prior to ginning, optimizing supply allocation for spinner mills.
- **Real-Time Data Capture**: Provides live traceability data feeds and interactive visualizations to let brands monitor compliance and material flows.
- **Role Privileges & Access Control**: Robust multi-tenant dashboard with defined role hierarchies for Farmers, Ginners, Spinners, Weavers, and Brands.

## Technologies Used

- **React & Next.js**: Built clean, modular user interfaces for diverse global stakeholders.
- **Node.js (Express)**: Scales backend operations, transaction validation, and batch processing.
- **PostgreSQL**: Stores relational transactional logs and historical traceability datasets.
- **AWS Services**: Utilizes Amazon S3 for invoice document storage and secure EC2/RDS instances for cloud scaling.
- **AI/LLM Pipelines**: Used for parsing document layout and mapping values into structured databases.

## Challenges and Learnings

Scaling the transaction verification pipeline across multiple cross-border entities required optimizing complex SQL joins and designing reliable background task runners. Offloading heavy analytical calculations (such as anomaly graphs) to asynchronous query views and implementing Redis caching significantly reduced dashboard loading times under heavy usage.
