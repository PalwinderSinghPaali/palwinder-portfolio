## Overview

`docx-templer` is an open-source, high-performance Node.js utility designed to simplify document manipulation, specifically for merging and embedding DOCX documents using placeholders. The package was created to solve common limitations in traditional document parsing (such as XML split runs generated by Microsoft Word) without requiring heavy OS-level dependencies or Microsoft Office automation.

By utilizing a buffer-based API, it is highly optimized for cloud platforms, serverless functions (like AWS Lambda or Vercel), and standard backend APIs.

## Key Features

- **Split Run Normalization**: Word processors often break up placeholder strings (like `{placeholder}`) into separate XML tags (split runs). `docx-templer` normalizes these elements to ensure reliable placeholder matching.
- **Buffer-Based Architecture**: Avoids writing temporary files to disk, allowing you to ingest buffers directly and output a unified, completed DOCX buffer.
- **Clean Merge APIs**: Simplifies embedding child documents into a parent template using clean, single-line functions.
- **Zero OS-Level Dependencies**: Requires no native Word installation or local wrappers, making it cross-platform compatible and extremely lightweight.

## Installation & Usage

You can install the package directly via npm:

```bash
npm install docx-templer
```

### Basic Example

```javascript
const { DocxTempler } = require('docx-templer');
const fs = require('fs');

const templateBuffer = fs.readFileSync('template.docx');
const childBuffer = fs.readFileSync('child.docx');

const templer = new DocxTempler(templateBuffer);
templer.embed('child_document_placeholder', childBuffer);

const outputBuffer = templer.compile();
fs.writeFileSync('output.docx', outputBuffer);
```

## Technologies Used

- **Node.js**: The library is built natively for Node runtimes.
- **XML Parser & Manipulator**: Handled structural zip and XML parsing inside standard OpenXML zip layouts.
- **Vitest / Jest**: Configured for continuous integration testing and package validation.
